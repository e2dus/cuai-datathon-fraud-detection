# 전처리 요약 (피처만, `catboost.ipynb`)

**공통:** 월 단위는 대체로 `×(52/12)`로 주 단위로 맞춤. 시간당 비율(`req_rate_`*)은 `×(24×7)`로 주당으로 맞춤. Train에서 쓴 중앙값·분위수는 Train 기준만 사용, Test에는 그대로 적용.

---

## 원본 컬럼 → 어떻게 했나


| 피처                                                                                       | 전처리                                                                |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `credit_risk_score`                                                                      | 0 미만은 0으로                                                          |
| `is_home_phone_valid`                                                                    | 0~1로 맞추고 반올림                                                       |
| `yearly_income`                                                                          | 값은 그대로. Train 하위 10%·상위 10%면 각각 플래그 컬럼 추가                          |
| `name_email_sim`                                                                         | 0~1로 자르기. 0.3 이하면 저유사 플래그 컬럼 추가                                    |
| `curr_addr_months`                                                                       | -1이면 Train 중앙값으로, 결측 플래그. 윗쪽 극단 자르기(q99) → 주 단위 → 짧게 산 플래그 → log1p |
| `prev_addr_months`                                                                       | -1이면 중앙값, 결측 플래그 → 주 단위 → log1p                                    |
| `init_transfer_amt`                                                                      | 음수는 Train에서 “큰 양수” 구간 평균으로 대체                                      |
| `req_credit_limit`                                                                       | Train 극단 잘라내기(q0.5~q99.5) → log1p                                  |
| `session_length_min`                                                                     | 음수는 0, 극단 잘라내기 → log1p                                             |
| `days_since_req`                                                                         | 7일 이내면 플래그. 극단 자르기(q99) → 주 단위(/7) → log1p                         |
| `req_rate_6h`, `req_rate_24h`, `req_rate_4w`                                             | 음수는 0 → 주당으로 환산 → log1p                                            |
| `zip_req_count_4w`                                                                       | 0보다 크면 플래그 → 주당(/4) → log1p                                        |
| `branch_req_count_8w`                                                                    | 음수는 0, 0보다 크면 플래그 → 주당(/8) → log1p                                 |
| `bank_months_count`                                                                      | -1이면 중앙값, 결측 플래그 → 주 단위                                            |
| `dob_email_count_4w`                                                                     | 주당(/4) → 나이구간별 표준화(z) 컬럼, q99 넘으면 이상치 플래그 → 본 값은 log1p             |
| `month_idx`                                                                              | sin/cos 두 컬럼으로 바꾸고 원 컬럼 삭제                                         |
| `age_bucket`                                                                             | 원-핫 (나이 구간 여러 컬럼으로 쪼갬)                                             |
| `payment_type`, `employment_status`, `housing_status`, `application_source`, `device_os` | 각각 원-핫                                                             |
| `is_foreign_req`, `is_session_persistent`                                                | 그대로 (노트북에서 추가 변환 없음)                                               |

## 새로 생긴 피처 (이름 + 의미)


| 피처                     | 뜻                                                                                |
| ---------------------- | -------------------------------------------------------------------------------- |
| `yearly_income_low`    | `yearly_income`이 Train 기준 **하위 10% 이하**이면 1                                      |
| `yearly_income_high`   | `yearly_income`이 Train 기준 **상위 10% 이상**이면 1                                      |
| `name_email_low_sim`   | `name_email_sim`이 **0.3 이하**(이름·이메일 유사도 낮음)이면 1                                  |
| `curr_addr_missing`    | 원래 `curr_addr_months`가 **-1(결측 코드)**이었으면 1                                       |
| `curr_addr_short`      | 현 주소 체류를 주 단위로 바꾼 뒤, Train **1사분위(q25) 이하**면 1(짧게 산 편)                           |
| `days_req_within_7`    | 원래 `days_since_req`가 **7일 이하**(최근 신청)이면 1                                        |
| `zip_req_gt_0`         | 4주 우편번호 신청 수가 **0보다 크면** 1                                                       |
| `branch_req_gt_0`      | 8주 지점 신청 수가 **0보다 크면** 1                                                         |
| `bank_months_missing`  | 원래 `bank_months_count`가 **-1**이었으면 1                                             |
| `prev_addr_missing`    | 원래 `prev_addr_months`가 **-1**이었으면 1                                              |
| `dob_email_z_age`      | `dob_email_count_4w`를 주당으로 나눈 값을, **같은 `age_bucket` 안에서** Train 평균·표준편차로 z-score |
| `dob_email_hi_outlier` | 위 주당 건수가 Train **99%분위 초과**이면 1                                                  |
| `month_sin`            | `month_idx`(0~7)를 **8개월 주기**로 sin 인코딩                                            |
| `month_cos`            | 같은 주기의 **cos** 인코딩 (`month_idx` 컬럼은 제거됨)                                         |


### 원-핫으로만 생기는 컬럼 (0/1)


| 근거 컬럼                | 생기는 피처 예시                                                   |
| -------------------- | ----------------------------------------------------------- |
| `age_bucket`         | `age_bkt_10`, `age_bkt_20`, … (나이 구간 문자열당 1개 컬럼, 노트북 기준 9개) |
| `payment_type`       | `payment_type_…` 형태 (값마다 컬럼)                                |
| `employment_status`  | `employment_status_…`                                       |
| `housing_status`     | `housing_status_…`                                          |
| `application_source` | `application_source_…`                                      |
| `device_os`          | `device_os_…`                                               |


Train에 있던 범주만 컬럼이 생기고, Test에만 있는 값은 해당 컬럼이 없거나(재정렬 시) 0으로 맞춤.
