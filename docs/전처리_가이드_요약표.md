## 피처사진 6·7 반영 업데이트 (핵심)

### 1) 상관계수 기반 단일 변수 판단 금지

- Spearman/Pearson 상관계수가 전반적으로 매우 낮고(상위권도 약 0.04~0.06), 부트스트랩 신뢰구간도 좁아 **우연한 저상관이 아니라 구조적 저상관**으로 판단됩니다.
- 결론적으로, 단일 변수 임계값만으로 사기를 분리하려는 접근은 한계가 큽니다.

### 2) 선형 모델은 기준 모델로만, 실전은 트리 앙상블

- 로지스틱 회귀·선형 SVM 같은 선형 모델은 주력으로 쓰지 않고, 진단용 베이스라인으로만 제한하는 것을 권장합니다.
- 실전 모델은 **LightGBM/XGBoost/CatBoost** 중심으로 유지합니다.

### 3) 전처리 우선순위 재정렬

- 스케일링 자체보다 **조합형·비율형·조건부 파생 피처**에 전처리 역량을 집중합니다.
- 핵심 권장:
	- 연령대(`age_bucket`) 조건부 상대 피처: diff/ratio/z-score
	- 요청률(`req_rate_*`) 비율 파생 + 다봉 구간화 + clip/log1p
	- MI 상위 이진 피처 유지 + 예외값 플래그 강화

### 4) 운영 체크리스트

- 원본 변수 제거 전에 반드시 OOF AP 기준으로 비교 실험
- 파생 피처는 Train 통계(평균/표준편차/분위수)로 만들고 Test에는 동일 기준 적용
- 최종 모델 선택 기준은 Accuracy가 아닌 **OOF AP(주 지표)** + ROC-AUC(보조 지표)
